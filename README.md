# Мерење ћирилизације

## Резултати мерења
Најсвежији резултати мерења ћирилизатора су [овде](https://docs.google.com/spreadsheets/d/1BdgZAWcbiBCXevWFoXaZj1CWzy-2T6hrhxsLT3e7sS4/edit?usp=sharing).

## Како се користи

### Припремање окружења
По клонирању репозиторијума потребно је преузети скупове података и припремити их за мерење ћирилизације. Овај корак треба обавити само једном.
```bash
# инсталација Питон виртуелног окружења
python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt

# активирај виртуелно окружење
. .venv/bin/activate

# преузимање скупова података
./scripts/download_data.sh

# генерисање латиничних улаза
./scripts/generate_latin.sh
```

### Направите докер
Експерименти са транслитерацијом се обављању у докер контењеру.

```bash
# направи докер контењер
./docker/build.sh
```

### Мерење транслитерације
Мерење свих транслитератора обавља скрипта [eval_all.sh](scripts/eval_all). Њу треба покренути унутар докер контењера:

```bash
# мери све алате за транслитерацију на свим сетовима података
./scripts/docker_eval.sh
```

### Резултати транслитерације
Излази из транслитератора се налазе у директоријумима:
```bash
# ${transliterator} : назив транслитератора
# ${dataset} : назив скупа података
# ${alphabet} : lat - латиница, ascii - ошишана латиница
out/${transliterator}/${dataset}/${alphabet}
```

Табела са метрикама за сваки транслитератор и је у TSV табели:
```
out/results.tsv
```

Табела изгледа овако:
| tool    | dataset   | alphabet   |   wer |   cer |   #words |   wins |   wsub |   wdel |   #chars |   cins |   csub |   cdel |
|---------|-----------|------------|-------|-------|----------|--------|--------|--------|----------|--------|--------|--------|
| srtools | tiny      | lat        |  2.36 |  1.02 |      806 |      0 |     19 |      0 |     5090 |      0 |     52 |      0 |
| srtools | tiny      | eng        | 18.36 |  3.71 |      806 |      0 |    148 |      0 |     5090 |      6 |    183 |      0 |
| srtools | tiny      | eng2       | 18.36 |  6.17 |      806 |      0 |    148 |      0 |     5090 |    131 |    183 |      0 |


### Сажетак резултата
Табела је због великог броја мерења тешка за разумевање. Зато треба пустити скрипте за извлачење XLSX фајла са сажетом резултата. 

```bash
# припрема xlsx са анализом резултата (out/results.xlsx)
./scripts/summarize_results.sh
```

Сажетак последњег мерења које смо ми урадили је [овде](https://docs.google.com/spreadsheets/d/1BdgZAWcbiBCXevWFoXaZj1CWzy-2T6hrhxsLT3e7sS4/edit?usp=sharing)

### Анализа грешака
Извлачење најчешћих парова погрешно транслитерираних речи и до 10 примера у којима се свака од тих грешака појављује:
```bash
# извуци најчешће грешке транслитерације
# излаз: analysis/${tool}/${dataset}/${alphabet}
./scripts/prepare_analysis.sh
```

Пример фајлова унутар директоријума:
```bash
# шаблон: ${count}_${expected_word}_${actual_word}
./002094_of_оф.txt
./001161_et_ет.txt
./001082_in_ин.txt
./000812_al.__ал._.txt
...
```
